# Subtrack - Phase 3 (frontend)

## Run it
Open `index.html` in your browser (double-click it). No install needed.
Optional local server: `npx serve .`

## What works
- Overview: monthly and yearly totals, budget ring, upcoming renewals, overlap tip
- Cards: search, filter by status/category, sort, add, edit, pause, cancel, delete
- Settings (gear icon): currency, monthly budget, reminder timing
- "Load sample data" on the empty screen for a quick demo
- Data is saved in your browser (localStorage). Clearing site data erases it.

## Logos
Put logo files in `assets/logos/` (see the README there). Without them, each service shows a colored initial.
